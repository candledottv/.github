# Contributing to Candle

Thanks for helping. Here's where each kind of change goes.

## Issues

Open an issue in the repository for the tool you use. Tell us:

- the command or tool you ran;
- the error you got back;
- what you expected.

Never paste a private key, seed phrase, API key or token.

## Pull requests

Read the repository's own `CONTRIBUTING.md` first. Some Candle repositories are built from Candle's monorepo, and the next sync overwrites any pull request opened there. In those, open an issue and describe the change instead.

- [candledottv/agentic](https://github.com/candledottv/agentic): the MIT source of the CLI, SDK, MCP server and agent skills. A read-only mirror.
- [candledottv/cli](https://github.com/candledottv/cli): signed releases of the Candle CLI.
- [candledottv/tui](https://github.com/candledottv/tui): signed releases, issues and docs for the Candle TUI.
- [candledottv/homebrew-tap](https://github.com/candledottv/homebrew-tap): the Homebrew formula. The release workflow updates it.

## Documentation

The docs live at [docs.candle.tv](https://docs.candle.tv). Report a docs problem as an issue in the repository closest to it.

## Security

Don't open a public issue for a vulnerability. Read [SECURITY.md](SECURITY.md).

## License

Each repository states its own license. Your contribution is accepted under it.
